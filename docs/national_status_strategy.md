# National-status strategy (milestone 3 design)

## Loop

```text
SGI metrics → peer data → gap → improvement options → cost / impact / time → priority roadmap
```

## Scorecard

For each NIRF-style dimension, the scorecard records:

| Field | Meaning |
|---|---|
| Current | SGI's current score |
| Peer median | Median of the peer set |
| Top-25 threshold | Score needed to reach the top 25 |
| Top-10 threshold | Score needed to reach the top 10 |
| Gap | Distance from the next threshold |
| Cost to improve | Estimated spend to close the gap |
| Time to improve | Estimated time to close the gap |
| P(success) | Chance the improvement lands |

Dimensions: teaching-learning resources, research & professional practice, graduation outcomes, outreach & inclusivity, perception.

**Peer sets:**
1. Bihar private institutions in the same category
2. Eastern India NIRF-ranked peers
3. Aspirational national peers

**Output:** the 5 investments with the highest expected score gain per rupee, not a list of 300 metrics.

## Roadmap milestones (1 / 3 / 5 / 10 years)

1. Best in district
2. Best in regional category
3. Recognised Bihar brand
4. Eastern India presence
5. Nationally respected programmes
6. Ranking competitiveness

Each milestone has a KPI threshold, budget, owner, dependencies and probability.

**Prerequisite:** AISHE data completeness and NAAC eligibility for each institution. Gaming is rejected: publication counts without quality, and MoUs without internships, are scored as low-value.
