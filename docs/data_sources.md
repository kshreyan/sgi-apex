# Data sources

## Public sources used in Phase 0 (checked 2026-11-03)

| Source | Used for | Reliability |
|---|---|---|
| https://subhwanti.com/institute.php | Institutes, schools, campuses, founding year 2011 | Official (institution claim) |
| https://subhwanti.com/accreditation-recognition.php | Regulators, affiliating universities | Official (claim + certificate PDFs) |
| https://subhwanti.com/leadership.php | Leadership roles | Official |
| https://pharma.subhwanti.com/ | Pharmacy programmes, PCI/BUHS, BSCC, address | Official |
| Careers360 (SIE Siwan, SIPE West Champaran) | B.Ed, D.Pharm and B.Pharm intakes, SIPE est. 2020 | Third-party estimate |
| Collegedunia (Hi-Tech Polytechnic) | Foundation link, SBTE affiliation 2016 | Third-party estimate |
| eastchamparan.nic.in, PM-JAY listings, Justdial | Chakia hospital search (no match) | Official / directory |

Facts are labelled as one of three kinds: **verified fact**, **institution claim** or **third-party estimate**.

## Authoritative external sources for later phases

- **Education regulators and rankings:** AISHE, NIRF, AICTE approval portal, NCTE, PCI, BCI, NAAC, NBA
- **University result portals:** AKU, BUHS, BEU, JPU, BRABU, SBTE
- **Bihar data:** BSEB (12th-grade output by district), Bihar Student Credit Card data
- **Demographics:** Census / NFHS
- **Labour market:** PLFS (employment)
- **Health:** NABH / NABL registries, ABDM Health Facility Registry, Bihar health department
